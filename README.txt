GAMING HUB
===========
Página principal + ficha de Minecraft 26.45.

Estructura:
- index.html
- game.html
- app.js
- styles.css
- data/games.json

Para añadir más juegos, edita data/games.json siguiendo el mismo formato.

IMPORTANTE:
Esta versión es una web estática. Los enlaces de descarga son los que proporcionaste.
Para publicar, sube toda esta carpeta a un hosting que sirva archivos estáticos y mantén la carpeta data.
